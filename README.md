# ABC Bookstore Chatbot

## 📖 Project Description
This project develops a chatbot for **ABC Bookstore** that provides automated customer support, book search functionality, personalized recommendations, and order tracking.  
The chatbot aims to improve customer experience, streamline support, and assist users in making informed purchasing decisions.

## 👩‍💻 Team Members
- Carolina Ortega R.

## 🎯 Initial Goals
- Develop a chatbot capable of handling customer inquiries and requests effectively.
- Automate responses to FAQs and common issues to reduce workload on human representatives.
- Provide book search functionality (title, author, ISBN, keywords, genre).
- Offer personalized book recommendations based on browsing and purchase history.
- Enable customers to check order status and access support channels.
- Support multiple languages (English and Spanish).
- Showcase promotions and bookstore branding in chatbot interactions.

## 🚀 Project Phases
1. **Project Initiation and Planning**  
2. **Development and Implementation**  
3. **Testing and Refinement**  
4. **Deployment and Launch**  
5. **Post-Launch Monitoring and Optimization**

## 📦 Deliverables
- Fully functional chatbot integrated into the ABC Bookstore website.
- Documentation on chatbot functionalities, usage instructions, and maintenance guidelines.
- Training materials for bookstore staff.
